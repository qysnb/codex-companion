# 0.6.2：可调的本地同步间隔

右键 → 额度设置 → 本地同步间隔。默认“即时（推荐）”保留原来的事件驱动方式：约35ms合并突发通知，约1秒进行元数据恢复检查。即时不是零秒循环轮询。

提供即时、0.5/1/3/5/10/30秒、1分钟和自定义。自定义输入0代表即时，或0.1–3600秒，最多三位小数。关闭本地同步时隐藏该间隔。三种界面语言一致。

固定间隔限制本地读取频率，期间通知合并；每批扫描后只发布原始时间最新的额度快照，不会积压后连续重放。固定档的元数据检查也跟随所选间隔。修改即时生效并保存，不重启订阅、不丢失文件偏移或更改联网模式/联网间隔。切回即时会唤醒现有订阅，长间隔不影响退出。

此设置只影响本地文件读取，不发起服务端请求；没有新额度事件时保留原值和读取时间。较长间隔会增加更新等待时间。缓冲仍有固定上限；长时间累积的数据分块读取并主动让出执行机会，每批只保留最新候选快照。

延后读取的事件按原事件时间判断数据新鲜度，不把刚读到的旧事件当作实时数据来阻止用户已开启的联网补充。身份元数据失效处理保持即时，不受读取间隔推迟。

验证：先复现“设定间隔后仍立即发布”的失败用例，再完成定向和完整控制台回归。真实临时文件测试覆盖频率限制、多事件/大于1MiB积压合并、运行中调整、即时唤醒、关闭与独立保存。WPF设置验证覆盖72组菜单、12组状态、12组输入和现有订阅绑定，未尝试联网或更改用户偏好。构建0警告/0错误。
