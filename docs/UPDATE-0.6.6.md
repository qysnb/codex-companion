# 0.6.6：额度设置匹配HTTP优先工作流

额度设置的主层现在依次显示：

1. 读取方式：定时查询、查看时查询、仅手动查询。
2. 查询间隔：仅定时模式显示，提供30秒及原有其他预设和自定义。
3. 立即刷新额度。
4. 当前来源和最近读取时间：使用当前额度服务的来源与读取时间，与额度气泡一致。
5. 本地事件辅助：集中本地事件开关、事件读取间隔、同步状态和本地读取时间。
6. 额度恢复提醒：保留原开关和已保存状态。

自动联网仍优先HTTP，特定失败限频回退兼容查询；本次只调整菜单组织、文案和自定义间隔说明。现有模式、30秒间隔和其他偏好保留，不添加定时器、进程、依赖或菜单打开时的网络请求。简中、英文、日文同步更新。

验证覆盖108组模式/语言/间隔/本地开关组合、12组额度来源和读取时间、12组本地状态、12组自定义输入、3组气泡时间以及运行中本地间隔绑定。全部离线执行。
