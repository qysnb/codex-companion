# 程序权限与数据

程序以普通用户权限运行，无需管理员权限。不提供网络监听、远程控制、进程注入、全局键盘／鼠标钩子、Windows 服务或计划任务。

窗口跟随只查询前台窗口的程序路径、窗口几何和显示器DPI，不读取聊天内容或编辑器文本。鼠标命中检测和窗口消息处理仅用于自身窗口。

控制入口是仅当前Windows用户可访问的命名管道，命令为固定允许列表。CLI不会把用户文字作为Shell命令执行。

## 本地订阅

0.6.0默认只读监听新追加的本地额度事件，不修改宿主或会话文件。仅event_msg/token_count的rate_limits进入解析；其他记录在有界头部筛选后丢弃，不解析/输出消息正文。没有复制会话文件或保存登录信息。本地监听器对auth.json仅监听元数据；变化后清空旧缓存和代次。监听器拒绝重解析点路径，缓冲、文件和事件队列有上限。

这是内部文件格式，无法保证每个宿主版本都可用。启动不回放旧额度；没有新事件时不能声称实时数据。本地事件不含已验证账户身份，不会与已验证联网缓存拼接窗口。0.6.4起，本地新事件也可根据同一有效订阅内实际0%→100%变化触发恢复提醒，不宣称具备在线账户身份保证。来源切换、代次失效、检测到账户元数据变化或关闭同步会丢弃相关提醒基线；外部账户切换若未引发可观察失效，无法通过本地事件独立验证。显式联网读取仍独立确认账户。自动HTTP模式中，HTTP快照优先于可能滞后的本地事件。

## 联网与缓存

0.5.0默认采用本地缓存、仅手动联网，旧配置缺少联网方式字段时也采用本地模式。启动、普通点击、隐藏、失败退避和本地重置倒计时不主动查询额度；右键“立即刷新额度”或CLI `refresh-quota` 是明确联网请求，可能产生流量。图片、表情、动画和随机台词均从本地资源读取。

按需模式仅在点击额度页时读取，尝试间隔至少为 `max(900秒, 自动刷新间隔)`，失败也限频，不后台轮询。只有用户明确选择自动模式后才启用预取、周期刷新、失败重试和重置点读取，隐藏角色仍会查询。新自动间隔为900秒，原用户值保留；可在菜单选择30秒或其他间隔。

0.6.5联网优先读取CODEX_HOME/auth.json（默认当前用户.codex目录）内已有ChatGPT登录材料，只在当前进程内存中使用，不复制、持久化、输出或自行续期；不写auth.json。只向固定HTTPS地址https://chatgpt.com/backend-api/wham/usage发送Bearer和可选账户头，不跟随重定向，不使用Cookie，不支持将凭据发送到任意自定义地址；TLS证书按系统正常验证。连接池复用，每次GET只查询额度，不查询价格、历史、重置券或模型列表。响应解压后最多64KiB，请求超时10秒。账户标识在内存中以摘要比较，响应结束再次核对账户，避免在途换账户复用。

缺少可用登录材料、401/403、网络故障/超时、408、5xx或格式异常时，允许回退自身创建的独立stdio App Server，最多每15分钟一次；429、账户切换、主动取消、过大响应不触发回退。429遵守Retry-After，包括手动点击；失败自动重试至少等待所设间隔，连续三次失败至少60秒。App Server只读账户／额度接口，不创建聊天或推理任务，仅管理自身子进程；私有进程关闭插件、远程插件、模型发现、宿主技能发现、MCP和analytics，不改写宿主全局配置。不能保证第三方CLI内部完全没有其他通信，因此状态和测试单独统计回退次数。

额度只缓存在当前进程内，退出后清空，不写入设置文件。底部显示最近成功读取时间，原始额度数据时间保留用于新鲜度判断及悬停说明。本地复核只读取已定位的额度记录，更新时间不代表云端发生变化；旧快照不代表实时查询；重新联网仍先确认账户身份。账户变化、身份不可比较或退出登录时，不复用旧账户缓存。恢复提醒依据实际新数据中的0%→100%变化；本地订阅与已验证联网账户基线独立，不从本地倒计时或缓存重读制造恢复值。

## 设置与发布

设置保存在 `%LOCALAPPDATA%\CodexCompanion\settings.json`。开机启动默认关闭，只有用户在菜单开启后才写入当前用户的Run启动项。额度重置提醒默认开启，可单独关闭，不播放声音、不抢走键盘焦点。

程序目前未做代码签名。项目没有宣称任何安全软件认证或扫描通过。无需关闭安全软件、添加排除项、绕过执行策略或关闭TLS验证。遇到告警请暂停运行，核对Release校验值并报告具体文件和版本；报告时隐藏账户、令牌、聊天和本机私人路径。

## 0.6.7根目录入口

根目录启动器为普通用户权限的原生Win32程序，按自身位置启动固定的app/bin/CodexCompanion.exe，不执行Shell、PowerShell、用户命令字符串、解压或网络请求。创建子进程后关闭自身句柄并退出，不新增常驻进程。依赖Windows自带KERNEL32、USER32与msvcrt。实际程序继续使用原权限和数据边界。已开启开机启动时，只修复自身已存在Run值的路径，不开启关闭的偏好、不重建系统中已删除的值。
