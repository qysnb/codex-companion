# 程序权限与数据

程序以普通用户权限运行，无需管理员权限。不提供网络监听、远程控制、进程注入、全局键盘／鼠标钩子、Windows 服务或计划任务。

窗口跟随只查询前台窗口的程序路径、窗口几何和显示器DPI，不读取聊天内容或编辑器文本。鼠标命中检测和窗口消息处理仅用于自身窗口。

控制入口是仅当前Windows用户可访问的命名管道，命令为固定允许列表。CLI不会把用户文字作为Shell命令执行。

## 本地订阅

0.6.0默认只读监听新追加的本地额度事件，不修改宿主或会话文件。仅event_msg/token_count的rate_limits进入解析；其他记录在有界头部筛选后丢弃，不解析/输出消息正文。没有复制会话文件或保存登录信息。auth.json仅监听元数据，内容从不打开；变化后清空旧缓存和代次。监听器拒绝重解析点路径，缓冲、文件和事件队列有上限。

这是内部文件格式，无法保证每个宿主版本都可用。启动不回放旧额度；没有新事件时不能声称实时数据。本地事件不含已验证账户身份，不能据此生成同账户重置提醒，也不会与已验证联网缓存拼接窗口。显式联网读取仍独立确认账户，保留原提醒功能。

## 联网与缓存

0.5.0默认采用本地缓存、仅手动联网，旧配置缺少联网方式字段时也采用本地模式。启动、普通点击、隐藏、失败退避和本地重置倒计时不主动查询额度；右键“联网刷新额度”或CLI `refresh-quota` 是明确联网请求，可能产生流量。图片、表情、动画和随机台词均从本地资源读取。

按需模式仅在点击额度页时读取，尝试间隔至少为 `max(900秒, 自动刷新间隔)`，失败也限频，不后台轮询。只有用户明确选择自动模式后才启用预取、周期刷新、失败重试和重置点读取，隐藏角色仍会查询。新自动间隔为900秒，原用户值保留。

额度通过本机Codex App Server只读账户／额度接口取得，不创建聊天或推理任务。共享代理不可用时，仅管理自身创建的临时stdio子进程，不会结束Codex桌面端。为减少附带通信，仅在该私有进程关闭插件、远程插件、模型发现、宿主技能发现、MCP和analytics，不改写桌面Codex的全局配置。应用不读取、复制或记录登录令牌。

额度只缓存在当前进程内，退出后清空，不写入设置文件。底部显示最近成功读取时间，原始额度数据时间保留用于新鲜度判断及悬停说明。本地复核只读取已定位的额度记录，更新时间不代表云端发生变化；旧快照不代表实时查询；重新联网仍先确认账户身份。账户变化、身份不可比较或退出登录时，不复用旧账户缓存。重置提醒只依据真实、同账户的0%→100%变化，本地倒计时不制造恢复值；本地模式需要后续手动读取才能观察变化。

## 设置与发布

设置保存在 `%LOCALAPPDATA%\CodexCompanion\settings.json`。开机启动默认关闭，只有用户在菜单开启后才写入当前用户的Run启动项。额度重置提醒默认开启，可单独关闭，不播放声音、不抢走键盘焦点。

程序目前未做代码签名。项目没有宣称任何安全软件认证或扫描通过。无需关闭安全软件、添加排除项、绕过执行策略或关闭TLS验证。遇到告警请暂停运行，核对Release校验值并报告具体文件和版本；报告时隐藏账户、令牌、聊天和本机私人路径。
