# 0.6.1：面向本地同步的设置菜单

主菜单保留语言、角色、大小、主题、页面持续时间、减少动画和日常操作。额度相关选项统一移入“额度设置”，不再在主菜单散列显示网络配置。

- “监听本地额度事件”改为“本地自动同步”，默认选择保持不变；增加等待宿主更新、已收到更新、暂停、暂不可用四种状态，收到事件后显示最近同步时间。
- “额度联网方式”改为“联网补充方式”：仅手动联网（推荐）、按需联网、定时联网补充。悬停说明补充条件、流量与本地同步的关系。
- “联网补充间隔”仅定时模式显示，提供1/5/15/30/60分钟和自定义5–3600秒。既有15秒等自定义值保留并显示为当前自定义选择，不擅自调整联网偏好。
- 手动操作改名“联网刷新一次”；重置提醒标为“额度恢复提醒（联网确认）”，说明仅联网确认同账户0%→100%后提醒，本地同步不会单独触发。
- 自定义间隔窗口及额度气泡的悬停说明同步更新，中文、英文、日文一致。气泡正文、同步链路和已有设置值保持原行为。

验证：构建0警告/0错误；原生WPF菜单检查覆盖36组语言/联网方式/本地开关/旧间隔组合和12组同步状态，打开菜单不更改偏好、不尝试网络连接；已渲染检查菜单预览。没有新增常驻计时器、查询进程或运行时依赖。
