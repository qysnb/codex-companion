# 安装与卸载

## 直接运行

从 [GitHub Releases](https://github.com/qysnb/codex-companion/releases/latest) 下载运行包。请使用Release附件中的两个运行ZIP；GitHub自动生成的Source code ZIP仅包含源码，需要自行构建。程序使用普通用户权限，不经过控制台脚本。

解压 `codex-companion-win-x64.zip`，双击包中 `marketplace/plugins/codex-companion/bin/CodexCompanion.exe`。此包带 .NET 8 Desktop Runtime，无需开发 SDK 或管理员安装。请保留 exe 旁边的运行时和 assets 文件夹。

若使用 `codex-companion-lite-win-x64.zip`，需事先安装 .NET 8 Desktop Runtime x64，建议使用微软提供的最新安全修订版本。Lite 版磁盘包更小，运行行为相同。程序不会替你安装系统运行时。

Lite 包的解压根目录名为 `marketplace-lite`；下文安装源路径相应指向这个目录。

首次启动默认 Q 版、简体中文、240 DIP。Codex 在后台时角色自动隐藏；在 Codex 前台等待最多约 1 秒即可出现。显示区域位于客户端右下角，拖动可调整位置。

当前版本0.6.3，提供Astra、Sol、Luna、Fable、Haiku、Pro、Flash，前三位的内部形象ID保持不变。待机使用闭嘴图，问候使用眯眼图，用量使用张嘴图；气泡关闭后回到待机。三张完整人物经过对齐，表情轻量过渡；左键点击时面部与身体统一压缩回弹后恢复。按住角色至少350毫秒后再拖动才会调整位置，点击、表情和气泡不改变保存位置。

右键“大小”提供小杯180、中杯240、大杯320和超大杯420逻辑像素。旧设置继续有效；默认档位不变。较小工作区会限制实际显示尺寸，额度气泡在上下空间不足时可放在侧边。

## 额度与流量设置

右键 → **额度设置**：默认开启“本地自动同步”，联网补充方式为“仅手动联网（推荐）”。同步状态和最近读取时间也在此显示。 启动和普通点击不发起联网查询；宿主新额度事件自动更新内存缓存。首次不回放旧事件，需要等宿主下一条新事件，也可右键“联网刷新一次”。图片、动画和随机台词均在本地运行。

额度设置中的“联网补充方式”有三项：

| 方式 | 行为 |
| --- | --- |
| 仅手动联网（推荐） | 监听宿主新写入的本地额度事件；仅明确选择“联网刷新一次”或 CLI `refresh-quota` 时联网 |
| 按需联网 | 点击额度页才可能读取，每次尝试至少间隔 `max(900秒, 自动刷新间隔)`，失败也限频；不后台轮询 |
| 定时联网补充 | 主动选择后启用预取、周期刷新、失败重试和重置点读取；隐藏角色仍会查询，可能产生较多流量 |

额度设置中的“本地自动同步”可独立关闭订阅。“本地同步间隔”默认即时，可选0.5/1/3/5/10/30秒、1分钟，或自定义0.1–3600秒（0代表即时）。固定档限制本地读取频率、合并期间事件，仅发布最新快照；运行中修改立即生效并保存，不影响联网补充设置。该通道只读CODEX_HOME/sessions中额度事件，不读取凭据或解析消息正文；auth.json仅监听元数据变化。没有新事件不推测额度恢复；本地事件无已验证账户身份，不触发账户验证型重置提醒。文件格式变化时不自动改为联网查询，详情见[0.6.0说明](UPDATE-0.6.0.md)。

“联网补充间隔”只在定时联网模式显示，提供1/5/15/30/60分钟和自定义5–3600秒，新设置默认 **900秒**。旧间隔数值保留，但配置缺少联网方式字段时采用本地模式，旧的60秒等设置不会自行开启后台查询。修改间隔也不会启用自动模式。任一模式都可明确手动刷新，并发请求合并；切本地会取消尚未转为明确手动请求的自动读取。

额度仅缓存在内存中，退出后清空。“读取于”显示本地或联网最近一次成功读取时间；本地会按同步间隔复核已定位的额度记录，即使没有新事件也会在成功后更新时间。原始额度数据时间在底部悬停说明中保留，读取时间不等于服务端数据新鲜度。共享代理不可用时使用自己的临时stdio子进程，仅在该进程关闭插件、远程插件、模型发现、宿主技能发现、MCP和analytics，不改写桌面Codex的全局配置。当前CLI 0.166系列的一次手动读取代理样本约0.595MB，不代表每轮固定消耗或长期流量保证。

额度设置中的“额度恢复提醒（联网确认）”默认勾选，可关闭并保存。同一已验证账户的真实读取从实际0%恢复为100%后，显示一次8秒无焦点提醒，两个窗口同时恢复合并提醒。本地模式需要后续手动读取，按需模式也不保证在重置时刻即时提醒；本地倒计时不推算额度恢复。首次读取为100%、未知值、旧缓存或账户切换不触发。

额度读取超时会丢弃该临时连接。仅自动模式按5／15／60秒退避重连，本地和按需模式不后台重试。读取状态和重连在后台处理，气泡保留额度数据，不显示重试横幅；失败本身不推进读取时间，其他来源的成功读取仍正常更新时间。账户暂时无法验证时隐藏旧值，确认仍是原账户后才可恢复；换账户或身份不可比较时不复用旧账户缓存。

账户／额度请求超时上限为30秒，初始化为10秒；缓存显示不等待网络，首次手动取得新数据仍可能等待数秒或更久。更新时先退出旧桌宠，将新包完整解压到单独目录后启动，原有设置会沿用，旧配置缺失的联网方式采用本地模式。

## 安装 Codex 插件

将解压目录长期保留，然后在普通终端执行，将示例绝对路径换成自己解压得到的 marketplace 目录：

```powershell
codex plugin marketplace add 'F:\你的目录\marketplace'
codex plugin add codex-companion@codex-companion-local
```

重新打开 Codex 聊天后，可让它显示／隐藏伴侣、切换形象或语言、刷新额度、读取状态。插件仅提供调用入口，实际桌面功能由伴侣 exe 执行。

无需 PowerShell 启动脚本、执行策略覆盖、白名单或关闭安全软件。本次开发没有自动注册用户插件或启用开机启动。

## 命令与诊断

在普通终端从 exe 所在目录执行：

```powershell
./CodexCompanion.Cli.exe --command show
./CodexCompanion.Cli.exe --command set-character --value elegant
./CodexCompanion.Cli.exe --command set-language --value ja
./CodexCompanion.Cli.exe --command set-refresh-interval --value 900
./CodexCompanion.Cli.exe --command get-status
./CodexCompanion.Cli.exe --command refresh-quota
./CodexCompanion.Cli.exe --command exit
./CodexCompanion.exe --check-assets
```

日常控制命令通过 `.Cli.exe` 输出JSON并退出，不常驻。`get-status` 只读本地快照，包含 `quotaNetworkMode` 和刷新间隔；`refresh-quota` 是明确联网请求，返回后读取可能仍在进行。

GUI exe 的 `--probe-quota` 是主动联网的开发诊断入口，不用于日常离线状态检查；`--check-assets` 为离线素材检查。某些PowerShell宿主可能不等待GUI exe退出，需要完整输出时可使用 `Start-Process -Wait -RedirectStandardOutput` 保存到自己指定的普通文件。

设置位于 `%LOCALAPPDATA%\CodexCompanion\settings.json`，不含登录信息。开机启动只有在右键菜单中主动开启后才写入当前用户的 `Run\CodexCompanion` 项。

## 卸载

先在角色右键菜单关闭“开机启动”（如果曾开启），再退出伴侣。在终端运行 `codex plugin remove codex-companion@codex-companion-local`，通过 `codex plugin marketplace remove --help` 查看本机版本对应的移除源命令。最后删除自己解压的文件夹；可选择保留或删除上述 settings.json。卸载不涉及 Codex 登录文件、聊天或角色原始参考图。

右键角色 → 主题，可分别设置额度文字和进度条颜色。选择预设，或输入 #RRGGBB，查看预览后保存；取消不会修改当前配色。

右键角色 → 页面持续时间：1s、3s、5s、10s、永久、自定义。默认两种气泡均为10秒；旧默认配置自动使用10秒，手选其他档位仍保留。自定义输入1–86400之间的整数秒；保存后重启保留，仍打开的气泡从新时长重新计时。永久不自动关闭，可点×关闭。

倒计时仅在鼠标悬停气泡本身、菜单或设置窗口打开时暂停。点击后鼠标停在角色上不会暂停。自动关闭由现有250毫秒界面检查处理，可能有一个检查周期左右的误差。
