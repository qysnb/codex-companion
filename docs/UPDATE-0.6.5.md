# 0.6.5：HTTP 优先额度读取

- 联网时优先只读现有登录材料，在进程内存中向固定 HTTPS 额度接口查询。不复制凭据、不自行续期、不创建推理任务。
- 复用一个 HTTP 客户端和连接池，每轮仅 GET 额度。无重置券、价格、历史用量或模型发现请求。
- 请求超时10秒，响应最大64KiB；关闭重定向和Cookie，正常验证TLS。
- 缺少可用凭据、401/403、408、5xx、连接/超时或无效格式时，最多每15分钟尝试一次独立 App Server 回退。429、取消、换账户和过大响应不启动回退。
- 429遵守Retry-After；自动失败重试不早于所设间隔，连续三次失败至少60秒。
- 设置新增30秒联网间隔，以及固定允许值的CLI命令set-network-mode。升级保留用户原有联网方式；30秒自动模式需明确选择。
- 自动HTTP模式以HTTP额度和成功读取时间为准，本地事件不会覆盖它或阻止定时查询。仅本地模式仍不自动联网。
- 防止旧的已过期额度周期覆盖另一个来源的新周期；过期窗口显示“待同步”，不伪造100%。
- 状态新增quotaTransport统计，只有计数、HTTP状态、耗时、响应正文大小和回退次数，不含身份或令牌。正文大小不代表网络流量总量。

额度接口属于内部端点，稳定性不作保证；所有显示和恢复提醒以实际收到的数据为依据。

## 本机测量

真实测试：2026-11-02 12:38:03–12:48:03（北京时间），持续600.05秒；30秒配置下HTTP20次、成功20次、失败0次，回退0次。上传43,526字节、下载50,951字节，共94,477字节（94.48KB，十进制）。首次5651.5ms，后续中位549ms、范围472–792.5ms，平均成功读取间隔30.582秒。只观察到一个桌宠进程、一条chatgpt.com连接，无未计量直连。该值为代理转发计数，不含IP/TCP包头、DNS、重传等；不是运营商账单。按相同速率连续24小时外推约13.60MB，并非全天实测。

上述网络正常样本没有触发失败回退；失败和回退分支另用合成凭据/响应测试。联网接口不保证始终可用或固定流量。
