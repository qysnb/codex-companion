# 0.6.0：订阅宿主本地额度事件

桌宠现在可以只读订阅 ChatGPT 内 Codex 或独立 Codex 已写入的本地额度事件。默认开启“监听本地额度事件”，联网方式仍默认本地；不启动额外 App Server，不调用模型，不轮询云端额度，不修改宿主或登录配置。

本地入口是当前用户 CODEX_HOME（未设置时为用户目录下.codex）的 sessions 事件流。FileSystemWatcher 接收追加通知，35ms合并突发通知，1秒检查已跟踪文件的长度以恢复遗漏通知；只有文件变长才读取。不是每秒请求服务端。

读取器先检查事件外层，仅接受 event_msg/token_count 的 rate_limits，其他类型在192字节头部筛选阶段丢弃，不解析其正文。只提取 codex 桶的300分钟/10080分钟窗口、已用比例和重置时间，气泡保留原事件时间。最多16个文件、每文件8KiB记录缓冲、共享8KiB读取缓冲；队列上限64项。没有复制会话文件、写入聊天记录或保存额度到磁盘。

启动不回放附加前的额度，等待宿主新事件；恢复旧聊天时只检查有界尾部，仍拒绝启动前事件。部分写入等到换行才处理，超长/损坏记录丢弃后恢复。新建、重命名、截断和通知恢复均有测试。auth.json仅监听元数据，不读取内容；变化使缓存和来源代次失效。重新解析路径时拒绝重解析点。

新本地事件和独立联网缓存按原始时间选择，整个快照切换，不跨来源拼接窗口；较旧的网络结果不能覆盖较新本地事件。按需/自动模式在本地数据新鲜时也避免重复读取，明确“联网刷新额度”仍可用。右键可关闭本地监听。get-status增加quotaSource、localQuotaSync和localQuotaSubscription统计，不包含会话路径、聊天正文或账户标识。

边界：这是现有本地事件文件格式，不是公开承诺稳定的ChatGPT外部API；格式不匹配时不编造数据，也不自动开启联网后备。没有新事件时保留上次值/时间，不推测重置为100%。外部管理的账户变化不一定修改本地auth元数据，本地事件不包含已验证账户身份，因此不用于生成“同一已验证账户0%→100%”提醒；明确联网确认的旧提醒路径保留，来源之间不沿用提醒基线。

真实用户环境初测：20秒收到2条真实宿主事件，事件时间戳至接收约58/64ms，固定读取缓冲32KiB；无独立查询进程。受工具沙箱限制的首轮不可访问目录，真实用户环境验证成功。最终安装后的持续更新和流量结果见GitHub发布说明；单次延迟不代表所有设备保证。

补充修复：离屏回归在0.5.0基线也复现问候框保留旧高度。内容已缩短但外框DesiredSize仍是旧值，现改为直接测量内容并加上边框/内边距，缓存键也包括页面类型。0.6.0的84组布局、24组主题、9组提醒及12组持续时间通过，真实5秒关闭约5025/5019ms，缓存额度显示最大107ms。
