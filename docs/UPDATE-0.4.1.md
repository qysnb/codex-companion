# 0.4.1：额度读取恢复与额度重置提醒

修复偶发“暂时无法读取 Codex 额度”时的连接恢复：请求超时后即使进程仍存在也丢弃当前连接，按现有5／15／60秒退避换连接重试。超时、连接问题和不可用响应分别标记，气泡显示自动重试时间。

缓存只在内存中保留。临时账户验证失败时不显示未经验证的旧数据，之后确认同一身份时恢复原始额度和时间，继续以过期状态呈现。账户变化、退出和未知身份不会拿到前一账户的缓存。旧连接捕获的通知不能改变新连接的数据；较旧读取的失败不能覆盖后来成功的推送。连接释放失败不会中断刷新调度，关闭后迟到的连接也由自身释放。

右键“额度重置提醒”默认开启并保存选择。复用真实额度的刷新和通知，按窗口检测同一账户0%到100%的实际变化，8秒无焦点弹窗、可手动关闭、最多一个。同时重置合并；首次100%、重复推送、账户变化不误报，读取失败和未知窗口不伪造恢复。不增加轮询、第三方依赖、驻留进程或常驻计时器；弹窗存活时才启动一次性关闭计时器。

边界：真实接口本身仍可能超时；首次冷网络读取不能承诺150ms。提醒依赖服务端实际返回，退出期间不追溯，未观测到0%也不提醒。重置测试使用明确的合成数据，不消耗用户额度来触发真实耗尽／恢复。
