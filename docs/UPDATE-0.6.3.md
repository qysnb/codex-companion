# 0.6.3：统一读取时间与本地额度复核

旧版气泡的“读取于”直接显示宿主额度事件时间，宿主空闲不写新事件时就一直停留在旧时间。本版将读取活动时间和额度数据时间分开处理。

- “读取于”统一显示本地或联网最近一次成功取得额度记录/结果的时间，两条来源同等参与。失败和单纯打开气泡不会伪造成功时间。
- 本地同步按已有间隔复核最近一条已定位的额度记录，即时模式约1秒兜底检查；只重新读取这条最多8KiB的记录并校验内容和换行，不重复扫描整个会话。复用原有缓冲，不增加查询进程或联网。
- 复核不增加“新宿主事件”计数，get-status分别提供quotaReadAt、quota.updatedAt、localQuotaSubscription.lastReadAt/rechecks；原始数据时间不会被复核时钟改写。
- 当前额度仍优先选择数据时间较新的完整快照，避免旧本地值覆盖较新联网值；数据时间相同时按最近成功读取顺序选择，不固定偏向本地或联网。
- 悬停气泡底部可查看当前额度的原始数据时间；菜单“最近同步”改为“最近读取”。没有宿主新数据时额度值仍可能不变，读取时间不等同于云端发生变化的时间。
- 文件缺失、记录改变/损坏或账户代次失效时不推进成功时间。账号失效清除相关缓存和读取时间；恢复/提醒身份边界不变。

验证：完整控制台回归和真实临时文件复核测试通过，涵盖空闲无新事件、部分写入后的记录定位、读取失败、账户失效、平等来源排序与不回滚较新数据。三语底部时间/说明检查通过；84组气泡布局通过，缓存显示最大约123ms，5秒关闭约5017/5016ms。安装后静默窗口验证见发布说明。
