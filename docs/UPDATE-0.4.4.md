# 0.4.4

- 额度气泡移除角色名标题，五小时和周限额各自显示一行信息与4DIP细条，条长表示剩余百分比。
- 信息行包括限额名称、本地重置时刻、距重置时长和剩余百分比；悬停重置时刻可查看完整日期。底部保留原始读取时间。
- 右键设置加入主题：五种预设、文字和进度条各自的 #RRGGBB 自定义颜色、保存前预览、取消及持久保存。
- 控件和冻结画笔复用，无新增常驻计时器、外部UI依赖或动画进度条，后台静默刷新保持原逻辑。

验证：应用构建无警告错误，控制台测试通过，84组角色/语言/尺寸布局、24组额度边界与主题检查、9组提醒布局通过。测试使用合成额度，不代表实时网络读取耗时；本机125%缩放，未宣称已实测所有物理多屏组合。
