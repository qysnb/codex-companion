# 0.6.4：本地额度恢复提醒

- 额度设置中统一显示“额度恢复提醒”，去掉“联网确认”字样及该项悬停说明。简中、英文、日文同时更新。
- 本地自动同步也能触发提醒：同一有效订阅内，新额度事件实际显示五小时或周额度从准确的0%变为100%时，复用已有8秒、无声音、不抢焦点的弹窗。两个窗口同时恢复时合并提醒。
- 反复读取同一条记录、重复100%、倒计时到零和首次读到100%均不提醒。缺少某个窗口时保留该窗口最后观察值；0.1%等不会被显示取整当作0%。
- 本地和联网基线独立；切换有效数据来源、订阅代次失效、检测到账户元数据变化或关闭本地同步会丢弃相应基线，避免跨来源沿用旧的0%。失效后的排队提醒不会显示。
- 提醒仍默认开启，原用户关闭选择保持有效。未添加联网请求、轮询计时器、辅助进程或第三方依赖；正常本地同步继续使用既有事件订阅。

提醒取决于实际接收到的新数据：没有宿主新事件时不能保证在预期重置时刻通知，较长同步间隔可能合并中间值。本地事件不包含已验证账户身份，通知表示当前有效本地订阅观察到恢复，不宣称具备联网账户验证保证。账户缓存和不同来源的额度窗口仍不混合。

验证：新增本地恢复用例先复现旧版不提醒，再通过定向与完整控制台回归；覆盖本地/联网来源隔离、重复抑制及失效处理。离线WPF检查通过72组菜单、84组角色/语言/大小布局、9组提醒布局和既有动画/关闭测试，设置检查尝试联网次数为0。测试使用明确标记的合成额度，不声称实测等待了真实账户耗尽并恢复。
